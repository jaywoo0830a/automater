Automater API Guide v2

openapi.yaml (OpenAPI 3.2.0, 98 operations)과 함께 사용합니다.
Base URL: /api/v2  |  인증: Authorization: Bearer {token}

두 가지 사용자 유형:
일반 민지 — 엑셀 업로드 → 버튼 클릭 → 발송. 내부 구조를 모름.
전문 운영자 — 토큰/키워드/접사를 직접 제어. 커스텀 레이아웃, 프리셋 관리.

2. 일반 사용자 플로우

민지의 워크플로우: 캠페인 생성 → 엑셀 업로드 → 솔트 추가 → 조합 생성 → 발송 → 모니터링.
토큰, 키워드, 접사, 레이아웃은 시스템이 자동 처리합니다.

2.1 캠페인 생성

sequenceDiagram

    participant SPA
    participant API

    SPA->>API: GET /platforms

    API-->>SPA: {id:42, ...}
    SPA->>SPA: 캠페인 상세 페이지로 이동

3. 전문 사용자 플로우

운영자의 워크플로우: 모든 엔티티를 직접 제어합니다. 토큰 수동 구성, 키워드 개별 등록, 접사 직접 연결, 팔레트 아이템 개별 관리, 레이아웃 편집, 프리셋 설정 등.

3.1 수동 토큰 구성 → 타이틀 템플릿 편집

sequenceDiagram
    actor Op as 운영자
    participant SPA
    participant API

    Op->>SPA: 캠페인 상세 → 토큰 편집기
    SPA->>API: GET /campaigns/42/tokens
    API-->>SPA: [{slug:"region", type:"keyword"}, ...]
    SPA->>SPA: 파생 템플릿: "{region} {subject}"

    Op->>SPA: 리터럴 토큰 "전문" 추가
    SPA->>API: POST /campaigns/42/tokens
{slug:"_lit", token_type:"literal", value:"전문"}
    API-->>SPA: {id:99, ...}

    Op->>SPA: 풀 토큰 "cta" 추가
    SPA->>API: POST /campaigns/42/tokens
{slug:"cta", token_type:"pool", palette:{items:["지금 신청","무료 상담"]}}
    API-->>SPA: {id:100, palette:{items:[...]}}

    Op->>SPA: 드래그로 순서 변경
    SPA->>API: PUT /campaigns/42/tokens/reorder
{token_ids:[10, 99, 11, 100]}
    API-->>SPA: [sorted tokens]
    SPA->>SPA: 파생 템플릿: "{region} 전문 {subject} {cta}"

    Op->>SPA: 미리보기
    SPA->>API: GET /campaigns/42/preview-title?seed=42
    API-->>SPA: {template: "...", sample_title: "강남 전문 수학 지금 신청"}

    keywords }o--o{ affixes : "keyword_affixes M2M"
    keywords }o--o{ combinations : "combination_keywords M2M"

    campaign_palettes ||--o{ palette_items : contains
    campaign_keyword_picks }o--|| keywords : selects
    campaign_affix_overrides }o--|| keywords : targets
    campaign_affix_overrides }o--|| affixes : targets

    combinations }o--o| spacing_rules : uses
    combinations ||--o{ batch_items : assigned
    batches ||--o{ batch_items : contains
    batches }o--|| accounts : uses

7. 프론트엔드 구현 가이드

7.1 파생 템플릿 클라이언트 렌더링

function deriveTemplate(tokens) {
  return tokens
    .sort((a, b) => a.sort_order - b.sort_order)
    .map(t => t.token_type === 'literal' ? t.value : `{${t.slug}}`)
    .join(' ');
}
