Chapter 2

제목 파이프라인 데이터 맵

제목은 다섯 가지 데이터의 조합으로 만들어진다. 각각 Step 2의 하위 영역에서 제어한다.

classDiagram class Title { +string result } class A_Keywords { KeywordCategory Keyword CampaignKeywordPick } class B_Affixes { Affix (global dict) keyword_affixes (M2M) CampaignAffixOverride } class C_Pools { CampaignPalette PaletteItem } class D_Spacing { SpacingRule pattern: slug→0 or 1 } class E_TokenOrder { TemplateToken CampaignSlot } A_Keywords --> Title : fills keyword tokens B_Affixes --> A_Keywords : modifies values C_Pools --> Title : fills pool tokens D_Spacing --> Title : joins tokens E_TokenOrder --> Title : arranges all

그림 2-1. 제목 데이터 5대 구성 요소와 DB 모델

구성 요소Step 2 영역역할예시조합 영향
A. 키워드2a keyword 토큰에 치환되는 값 region: 강남동, 수원시 카르테시안 곱
B. 접사2a 키워드 값을 변형 (접미/접두 제거) 강남동 → 강남, 수원시 → 수원 값 변형 (곱 아님)
C. 풀2b pool 토큰에서 랜덤 선택 salt_suffix: 추천, 즉시 가능 랜덤 (곱 아님)
D. 띄어쓰기2c 토큰 간 공백 on/off "Normal": 강남 수학, "Compact": 강남수학 스타일 수 × 곱
E. 토큰 순서2d 블록의 종류와 배치 순서 [region] [과외] [subject] [salt_suffix] 구조 결정

조합 공식: 총 포스트 수 = (키워드 카르테시안 곱) × (띄어쓰기 스타일 수)

5.1 키워드 + 접사 제어

키워드를 업로드하면 한국어 접사(동, 구, 시, 읍, 면, 리 등)가 자동 감지된다. 사용자는 접사를 유지할지 제거할지 키워드별로 토글할 수 있다.

sequenceDiagram actor User participant FE as Frontend participant API as API alt Upload new User->>FE: Upload keywords.xlsx FE->>API: POST /step2/keywords/upload API-->>FE: KeywordUploadPreview (with detected affixes) User->>FE: Click Import FE->>API: POST /step2/keywords/import (auto_detect_affixes=true) API-->>FE: "8 keywords, 3 affixes linked" else Browse existing FE->>API: GET /step2/keywords/categories API-->>FE: Keywords with affix info per keyword end User->>FE: Toggle affix off on "강남동" → "강남" FE->>API: PUT /step2/keywords/affix-overrides API-->>FE: "2 overrides updated"

프론트엔드는 affixes 배열이 있는 키워드 옆에 토글을 표시한다. active: true면 접사 유지("강남동"), active: false면 접사 제거("강남"). stripped_result는 제거 후 미리보기용 값이다.

PUT /step2/keywords/affix-overrides — 접사 토글

// Request
{
    "overrides": [
        { "keyword_id": 1, "affix_id": 5, "active": false },
        { "keyword_id": 2, "affix_id": 8, "active": false }
    ]
}

// Response 200
{ "success": true, "message": "2 overrides updated.", "updated_count": 2 }

active: false는 "접사를 제거하겠다"는 뜻이다. 이 설정은 제목 생성 시 _apply_affixes()에서 적용되어 "강남동"이 "강남"으로 바뀐다.

5.3 띄어쓰기 스타일

각 토큰 뒤에 공백을 넣을지 말지를 슬러그별로 토글한다. 여러 스타일을 만들면 같은 키워드 조합으로 다른 제목이 생긴다.

띄어쓰기 모델

// SpacingStyle — 하나의 이름 붙인 띄어쓰기 규칙
{
    "name": "Normal",
    "pattern": {
        "region": 1,       // region 뒤에 공백
        "subject": 1,      // subject 뒤에 공백
        "salt_suffix": 1   // salt_suffix 뒤에 공백 (마지막은 무의미)
    }
}

// pattern 값:
//   1 = 이 토큰 뒤에 공백 (기본값)
//   0 = 이 토큰 뒤에 공백 없음 (다음 토큰에 붙임)

UI 표현

// 스타일 "Normal": 모든 슬러그 뒤에 공백
//   region[1] subject[1] salt_suffix[1]
//   → "강남 수학 추천"

// 스타일 "Compact": region, subject 뒤에 공백 없음
//   region[0] subject[0] salt_suffix[1]
//   → "강남수학추천"

// 스타일 "Mixed": region 뒤에만 공백 없음
//   region[0] subject[1] salt_suffix[1]
//   → "강남수학 추천"

프론트엔드는 각 슬러그 이름 옆에 토글 스위치를 배치한다. 사용자가 토글을 클릭할 때마다 /step2/spacing/preview를 호출해 실시간 미리보기를 갱신한다.

POST /step2/spacing/preview

// Request
{
    "styles": [
        {
            "name": "Normal",
            "pattern": { "region": 1, "subject": 1, "salt_suffix": 1 }
        },
        {
            "name": "Compact",
            "pattern": { "region": 0, "subject": 0, "salt_suffix": 1 }
        }
    ],
    "token_slugs": ["region", "subject", "salt_suffix"],
    "keyword_selections": [
        { "slug": "region", "keyword_ids": [1, 2] },
        { "slug": "subject", "keyword_ids": [10, 11] }
    ],
    "count": 3
}

// Response 200
{
    "styles": [
        {
            "name": "Normal",
            "template": "{region} {subject} {salt_suffix}",
            "samples": ["강남 수학 전문 추천", "수원 영어 즉시 가능", "강남 영어 강력 추천"]
        },
        {
            "name": "Compact",
            "template": "{region}{subject} {salt_suffix}",
            "samples": ["강남수학 전문 추천", "수원영어 즉시 가능", "강남영어 강력 추천"]
        }
    ],
    "combination_multiplier": 2,
    "warnings": []
}

combination_multiplier는 띄어쓰기 스타일 수이다. 키워드 조합이 4개이고 스타일이 2개면 총 8개 포스트가 생성된다.

5.4 타이틀 빌더

모든 데이터를 조합한 최종 라이브 미리보기이다. 키워드 값, 접사 제거, 풀 랜덤 선택, 띄어쓰기 패턴이 전부 반영된 샘플 제목을 보여준다.

sequenceDiagram actor User participant FE as Frontend participant API as API User->>FE: Arrange token blocks note over FE: Collects all current state FE->>API: POST /step2/title/preview note right of API: title_tokens + keyword_selections + spacing_styles + affix_overrides API-->>FE: Samples per spacing style FE-->>User: Live preview

그림 5-2. 타이틀 빌더 — 전체 데이터를 한 번에 미리보기

POST /step2/title/preview

// Request
{
    "title_tokens": [
        { "type": "keyword", "slug": "region", "sort_order": 0 },
        { "type": "literal", "slug": "lit_1", "value": "과외", "sort_order": 1 },
        { "type": "keyword", "slug": "subject", "sort_order": 2 },
        { "type": "pool", "slug": "salt_suffix", "sort_order": 3 }
    ],
    "keyword_selections": [
        { "slug": "region", "keyword_ids": [1, 2] },
        { "slug": "subject", "keyword_ids": [10, 11] }
    ],
    "spacing_styles": [
        { "name": "Normal", "pattern": { "region": 1, "lit_1": 1, "subject": 1, "salt_suffix": 1 } },
        { "name": "Compact", "pattern": { "region": 0, "lit_1": 0, "subject": 1, "salt_suffix": 1 } }
    ],
    "affix_overrides": [
        { "keyword_id": 1, "affix_id": 5, "active": false }
    ],
    "count": 3
}

// Response 200
{
    "styles": [
        {
            "name": "Normal",
            "template": "{region} 과외 {subject} {salt_suffix}",
            "samples": ["강남 과외 수학 전문 추천", "수원 과외 영어 즉시 가능", "강남 과외 영어 강력 추천"]
        },
        {
            "name": "Compact",
            "template": "{region}과외{subject} {salt_suffix}",
            "samples": ["강남과외수학 전문 추천", "수원과외영어 즉시 가능", "강남과외영어 강력 추천"]
        }
    ],
    "total_combinations": 8,
    "warnings": []
}

affix_overrides의 keyword_id=1이 "강남동"이고 active=false이므로 "강남"으로 표시된다.

total_combinations = (region 2 × subject 2) × 2 spacing styles = 8.
